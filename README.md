# 🤖 Gemini AI Chatbot (Streamlit + Python)

An interactive AI chatbot powered by **Google Gemini API** with both:

- 🌐 **Web UI using Streamlit**
- 💻 **Command Line Interface (CLI)**

This project demonstrates how to build a real-time conversational AI application using Python and Google GenAI.

---

## 🚀 Features

- ✅ Interactive chat interface using Streamlit  
- ✅ Session-based message memory  
- ✅ Google Gemini 2.5 Flash model integration  
- ✅ Secure API key handling using `.env`  
- ✅ CLI chatbot for terminal usage  
- ✅ Easy installation with `requirements.txt`
